# Getting help

Use the repository that owns the behavior or documentation you are asking about.

1. Read its README and linked setup instructions.
2. Search open and closed Issues for the same problem.
3. Open an Issue with reproduction steps, expected and actual behavior, and relevant tool or operating-system versions.

Use the bug-report form for a reproducible problem and the feature/task form for a proposed improvement. Keep one concrete problem or outcome per Issue.

Repository access, credentials, and other account-specific matters should go through an existing private channel with a repository maintainer. Do not post passwords, tokens, private project contents, or account recovery information in public Issues.

These projects are under development. Availability of support and release plans is described by each project; no response-time commitment is made here.
