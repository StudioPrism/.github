# Studio Prism — organization resources

This repository maintains Studio Prism's GitHub profile and shared contributor resources.

| Location | Purpose |
| --- | --- |
| [profile/README.md](profile/README.md) | Public organization introduction and project directory |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Default contribution workflow |
| [SUPPORT.md](SUPPORT.md) | Where to ask for help |
| [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE/) | Default bug-report and feature/task forms |
| [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) | Default pull request checklist |
| [docs/repository-guide.md](docs/repository-guide.md) | Repository organization and maintainer setup guide |
| [projects/README.md](projects/README.md) | Historical planning material |

Repository-specific contribution files take precedence over organization defaults. Keep project implementation, build instructions, and active tasks in the relevant project repository.

The public profile lists public repositories only. Do not add internal project information, credentials, or unreleased material to this public repository.
